# RootStack | Portfolio Website

My personal portfolio website. It shows who I am, what I can do, and the projects I've built.

## Live Site

https://kudabii.github.io/Portfolio-website/

## Sections

- **Hero**: quick intro with links to my work and resume
- **About Me**: my background and what I do
- **Skills**: the tools and technologies I use
- **Projects**: things I've built
- **Contact**: how to reach me

## Built With

- HTML5
- CSS3 (Flexbox, media queries)
- Font Awesome icons

## Features

- Fully responsive (works on phones, tablets and desktops)
- Smooth scrolling navigation
- Downloadable resume
- WhatsApp contact link

## Run It Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/kudabii/portfolio.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
